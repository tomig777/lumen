## iPhone discovery and safety

The prior release already supplied reachable opaque PNGs and valid `apple-touch-icon` metadata. Its manifest additionally advertised an SVG. [WebKit 256429](https://bugs.webkit.org/show_bug.cgi?id=256429) describes this combination falling back to the default letter icon and the reporter recovering by removing SVG entries. This is a **plausible compatibility cause**, not a confirmed diagnosis of the user's iOS 17.3 installation. iOS may also retain previously installed icon artwork independently of app-shell updates.

The v2 release supplies fresh PNG-only favicon/touch/manifest URLs and a conventional touch-icon file; app identity/start URL/scope/full-screen mode and storage remain unchanged. PNG validation, reachable live resources and a browser preview do not prove the actual native Add to Home Screen icon. Check the ordinary site in Safari's Add to Home Screen sheet and cancel before installing. Do not delete an installed app or clear data. If a fresh installation is eventually needed, protect and verify the existing app's backup first: iOS does not copy IndexedDB/localStorage into a new Home Screen app ([WebKit iOS 17.2 notes](https://webkit.org/blog/14787/webkit-features-in-safari-17-2/)).
